使用说明

从第一次归档到安全释放空间

按照下面的步骤完成第一次 PhotoHarbor 工作流：添加目标、选择照片、等待 proof、处理阻断、再安全删除。

准备工作

准备一个可访问的 NAS、Mac / Windows 共享文件夹、WebDAV、SFTP 或云盘目标，并在 iOS 中授予 PhotoHarbor 照片访问权限。

完成以下准备后，再进入“添加存储目标”。第一次使用时，建议让 iPhone 或 iPad 与 NAS、Mac 或 Windows 电脑连接到同一个 Wi‑Fi，并优先使用 SMB。

PhotoHarbor 不要求你先把照片复制到电脑，也不要求把家中的 NAS 暴露到公网。App 只有在所选远端文件夹通过连接、写入、浏览和轻量读取检查后，才会把它保存为可用目标；本机照片也不会被自动删除。

✓

开始前快速检查

先确认下面七项，可以减少第一次连接时的反复排查。

  • 已准备一个专门存放照片和视频的远端文件夹。
  • 远端剩余空间足够容纳本次归档内容。
  • 知道服务器地址、端口、文件夹路径、用户名和密码，或已经准备好云盘账号。
  • iPhone/iPad 能访问目标所在网络；异地连接时已经接入 VPN。
  • 已允许 PhotoHarbor 访问需要归档的照片。
  • 已确认“仅在 Wi‑Fi 网络下上传”是否符合当前需求。
  • 在 PhotoHarbor 显示归档 proof 完成前，不手动删除本机原件。
01

先确定连接方式

选择存储方式

不同协议需要准备的信息不同。家庭 NAS 或电脑共享目录优先考虑 SMB；已有安全服务或需要异地访问时，再按实际环境选择 WebDAV、SFTP 或云盘。

家庭用户优先推荐

SMB

适合群晖、威联通、飞牛、Windows 共享文件夹和 Mac 文件共享。首次使用最容易配置，通常在同一局域网内使用。需要准备服务器 IP、共享文件夹、用户名和密码，默认端口为 445。

已有 WebDAV 服务

WebDAV

需要服务器地址、端口、文件夹路径、用户名和密码。服务器支持时应选择 HTTPS；HTTP WebDAV 不加密凭据和媒体内容，只应在完全可信的局域网中使用。

熟悉服务器管理

SFTP

需要开启 SSH/SFTP 服务，并准备服务器地址、端口、账号和远端绝对路径。可使用密码或私钥认证；私钥优先采用 Ed25519 或 ECDSA，当前不把 RSA 作为推荐方案。

不依赖家庭局域网

云盘

支持 Google Drive、Dropbox、OneDrive 和百度网盘。在 PhotoHarbor 内完成官方登录，再选择或新建归档文件夹，不需要手动填写 access token。Google Drive 只管理默认 PhotoHarbor 文件夹或用户明确选择授权的文件夹。

异地访问先连接 VPN

如果目标只在家中局域网可访问，而你当前不在家，请先连接家庭 VPN。不要直接把 SMB 445 端口暴露到互联网；异地访问优先使用 VPN、HTTPS WebDAV、SFTP 或云盘。

02

按设备完成共享与权限配置

准备 NAS 或电脑

下面的菜单名称可能因系统版本略有不同。每次只需展开你正在使用的平台；无论品牌如何，最终都要确保账号能在目标目录中创建、读取、重命名和删除文件。

群晖 SynologyDSM · SMB
  1. 登录 DSM，进入“控制面板 → 文件服务 → SMB”，开启 SMB 服务。
  2. 在“控制面板 → 共享文件夹”中新建或选择专用目录，例如 PhotoHarbor。
  3. 建议创建专用普通账号，并授予该目录读写权限；不要依赖 Guest 账号。
  4. 确认账号可以新建、读取、重命名和删除文件。
  5. 记录 NAS 的局域网 IP、共享文件夹名称、用户名和密码。
群晖 SMB 官方说明↗ 共享文件夹排查说明↗
威联通 QNAPQTS · SMB
  1. 登录 QTS，进入“控制台 → 网络和文件服务 → Win/Mac/NFS/WebDAV → Microsoft 网络”，启用 SMB。
  2. 在“权限 → 共享文件夹”中新建或选择归档目录。
  3. 为 PhotoHarbor 使用的账号授予读写权限，并限制匿名访问。
  4. 记录 NAS IP、共享目录、账号和密码；SMB 默认端口为 445。
  5. 如果设置了主机访问限制，确认 iPhone 所在网段没有被拒绝。
QNAP SMB 官方说明↗ 共享目录权限说明↗
飞牛 fnOSSMB / WebDAV / SFTP
  1. 进入“设置 → 文件共享协议”，开启 SMB；需要 SFTP 时进入“设置 → SSH”开启服务。
  2. 在“文件管理 → 我的文件 → 团队文件”中新建专用团队文件夹。
  3. 创建时允许该目录通过 SMB/WebDAV 等文件共享协议挂载。
  4. 为使用的账号授予“读写”权限，并确认该账号的文件共享可见范围包含此目录。
  5. 记录设备 IP、账号和目录原始路径。
飞牛文件共享权限说明↗ 团队文件夹说明↗
macOS文件共享 · SMB
  1. 打开“系统设置 → 通用 → 共享 → 文件共享”。
  2. 点击文件共享旁的信息按钮，在“选项”中开启“使用 SMB 来共享文件和文件夹”。
  3. 勾选允许通过 SMB 登录的 Mac 用户。
  4. 将归档目录加入共享文件夹，并给予该用户“读与写”权限。
  5. 记录 Mac 的局域网 IP、共享文件夹名称、用户名和密码；归档期间避免 Mac 进入睡眠。
Apple 官方 SMB 设置说明↗
Windows 11网络文件共享 · SMB
  1. 将当前网络配置为“专用网络”，并开启网络发现和文件及打印机共享。
  2. 在文件资源管理器中右键目标文件夹，选择“显示更多选项 → 授予访问权限 → 特定用户”。
  3. 为专用账号授予读取和写入权限；不建议长期使用无密码或 Everyone 完全控制。
  4. 确认 Windows 防火墙允许专用网络中的文件共享。
  5. 记录电脑 IP、共享名称、Windows 用户名和密码；上传期间保持电脑开机。
Microsoft 官方网络文件共享说明↗

与 App 表单逐项对应

准备连接信息

先把下面的信息记在手边。主机地址只填写 IP 或域名，不要把共享文件夹或目录路径拼在主机地址中。

App 字段应填写内容示例
显示名称只用于在 PhotoHarbor 中识别目标家庭群晖
主机地址IP 或域名，不填写文件夹路径192.168.1.20
端口SMB 常用 445、WebDAV 常用 443/80、SFTP 常用 22445

用户名/密码NAS、Mac、Windows 或服务器账号专用普通账号

使用独立普通账号

建议为 PhotoHarbor 使用独立普通账号和独立归档目录，不要直接使用 NAS 超级管理员账号。凭据保存在设备 Keychain 中，数据库和诊断报告只保留目标元数据及凭据引用。

“检查并保存”会做什么

通过完整的目标能力检查后才会保存

点击“检查并保存”后，PhotoHarbor 会检查是否能够连接、创建测试内容、提交或重命名文件、列出目录并执行轻量读取。测试成功后才保存目标，临时探测内容会尽力清理。页面必须显示“可用于归档”后，再进入下一步。

04

允许 App 读取所选内容并访问目标

授予系统权限

照片权限

第一次从“上传”进入选择流程时，允许 PhotoHarbor 访问照片。建议选择完整访问；如果选择有限访问，只能处理已授权的照片，后续新增照片可能需要在系统设置中更新授权范围。

本地网络权限

连接 NAS、Mac 或 Windows 时，需要允许本地网络访问。若曾拒绝，可到“iOS 设置 → 隐私与安全性 → 本地网络”重新开启 PhotoHarbor。

云盘授权

云盘登录在服务商官方授权页面完成。PhotoHarbor 不接收云盘登录密码，只保存完成操作所需的 OAuth 凭据。

iCloud 原件

如果 iPhone 开启了“优化 iPhone 储存空间”，部分原件可能只在 iCloud 中。首次大批归档前应保持稳定网络、足够的本机临时空间和电量，让系统能够下载所选原件。

05

避免任务因网络策略暂停

检查网络与上传设置

Wi‑Fi

“仅在 Wi‑Fi 网络下上传”默认开启。开启时，如果当前只有蜂窝网络，新建任务仍会创建，但会显示“等待 Wi‑Fi”，接入 Wi‑Fi 或有线网络后自动继续。浏览、预览、播放和删除校验不受这个开关影响。

  • iPhone/iPad 与 NAS 或电脑处于同一 Wi‑Fi 或可互通的 VPN。
  • 避免使用开启“客户端隔离”的访客 Wi‑Fi。
  • NAS、电脑、外接硬盘和目标卷保持在线。
  • 归档大视频时连接电源，并避免电脑自动睡眠。
  • 云盘账号授权有效，目标文件夹仍存在且可写。
  • 若允许蜂窝上传，在“设置”页关闭“仅在 Wi‑Fi 网络下上传”，并留意流量消耗。
06

确认可以安全开始第一次归档

完成归档前检查

  • 目标页面显示“可用于归档”。
  • 连接、写入、文件夹浏览和轻量预览检查均已通过。
  • 远端目录有足够剩余空间。
  • 当前账号拥有创建、读取、重命名和删除权限。
  • 已确定本次任务使用的远端文件夹。
  • 已理解冲突策略：重命名保留两份、跳过项不会获得 Safe Delete 资格、覆盖需要额外确认。
  • 已确认 Wi‑Fi 上传偏好。
  • 已理解“上传完成”不等于可以删除；必须等待最终归档 proof 完成，再进入 Safe Delete。

!

常见失败速查

连接检查没有通过时，先按错误类型排查，不要跳过检查直接开始归档。

目标不可达
检查 Wi‑Fi、VPN、服务器地址和端口。
认证失败
检查用户名、密码、SMB 域或 SFTP 私钥。
文件夹权限不足
换用可写目录，或补齐创建、重命名和删除权限。
远端空间不足
释放空间或选择其他目录。
无法浏览/轻量读取
重新运行连接检查；仍失败时改用其他协议或目标，避免进入不完整的 proof 链路。

添加存储目标

在 Targets 中添加目标并完成连接检查。云盘目标需要通过对应平台 OAuth 授权，并选择用于归档的文件夹。

创建归档任务

在 Archive 中选择目标、远端文件夹、冲突策略和照片/视频。任务创建后会进入后台队列。

等待归档证明

任务会经历上传、上传回执、提交、预览和最终归档证明检查。只有 proof 完成后，项目才具备 Safe Delete 资格。

PhotoHarbor 不会自动删除本机照片。只有通过 proof 的项目才会进入 Safe Delete 复核，最终删除仍需要用户确认。

安全删除

进入 Safe Delete 查看候选、proof 和阻断原因。需要时主动再次校验，最后通过双确认删除本机副本。

浏览与恢复

在 Timeline 浏览远端媒体库。你可以预览、分享或保存回 iPhone，但缓存预览不能替代原件。

PhotoHarbor

把照片归档到你自己的存储位置，在证明远端副本可读后，再决定是否释放本机空间。
