准备工作

完成以下准备后，再进入“添加存储目标”。第一次使用时，建议让 iPhone 或 iPad 与 NAS、Mac 或 Windows 电脑连接到同一个 Wi‑Fi，并优先使用 SMB。

PhotoHarbor 不要求你先把照片复制到电脑，也不要求把家中的 NAS 暴露到公网。App 只有在所选远端文件夹通过连接、写入、浏览和轻量读取检查后，才会把它保存为可用目标；本机照片也不会被自动删除。

✓

开始前快速检查

先确认下面七项，可以减少第一次连接时的反复排查。

  • 已准备一个专门存放照片和视频的远端文件夹。
  • 远端剩余空间足够容纳本次归档内容。
  • 知道服务器地址、端口、文件夹路径、用户名和密码，或已经准备好云盘账号。
  • iPhone/iPad 能访问目标所在网络；异地连接时已经接入 VPN。
  • 已允许 PhotoHarbor 访问需要归档的照片。
  • 已确认“仅在 Wi‑Fi 网络下上传”是否符合当前需求。
  • 在 PhotoHarbor 显示归档 proof 完成前，不手动删除本机原件。
01

先确定连接方式

选择存储方式

不同协议需要准备的信息不同。家庭 NAS 或电脑共享目录优先考虑 SMB；已有安全服务或需要异地访问时，再按实际环境选择 WebDAV、SFTP 或云盘。

家庭用户优先推荐

SMB

适合群晖、威联通、飞牛、Windows 共享文件夹和 Mac 文件共享。首次使用最容易配置，通常在同一局域网内使用。需要准备服务器 IP、共享文件夹、用户名和密码，默认端口为 445。

已有 WebDAV 服务

WebDAV

需要服务器地址、端口、文件夹路径、用户名和密码。服务器支持时应选择 HTTPS；HTTP WebDAV 不加密凭据和媒体内容，只应在完全可信的局域网中使用。

熟悉服务器管理

SFTP

需要开启 SSH/SFTP 服务，并准备服务器地址、端口、账号和远端绝对路径。可使用密码或私钥认证；私钥优先采用 Ed25519 或 ECDSA，当前不把 RSA 作为推荐方案。

不依赖家庭局域网

云盘

支持 Google Drive、Dropbox、OneDrive 和百度网盘。在 PhotoHarbor 内完成官方登录，再选择或新建归档文件夹，不需要手动填写 access token。Google Drive 只管理默认 PhotoHarbor 文件夹或用户明确选择授权的文件夹。

异地访问先连接 VPN

如果目标只在家中局域网可访问，而你当前不在家，请先连接家庭 VPN。不要直接把 SMB 445 端口暴露到互联网；异地访问优先使用 VPN、HTTPS WebDAV、SFTP 或云盘。

02

按设备完成共享与权限配置

准备 NAS 或电脑

下面的菜单名称可能因系统版本略有不同。每次只需展开你正在使用的平台；无论品牌如何，最终都要确保账号能在目标目录中创建、读取、重命名和删除文件。

群晖 SynologyDSM · SMB
  1. 登录 DSM，进入“控制面板 → 文件服务 → SMB”，开启 SMB 服务。
  2. 在“控制面板 → 共享文件夹”中新建或选择专用目录，例如 PhotoHarbor。
  3. 建议创建专用普通账号，并授予该目录读写权限；不要依赖 Guest 账号。
  4. 确认账号可以新建、读取、重命名和删除文件。
  5. 记录 NAS 的局域网 IP、共享文件夹名称、用户名和密码。
群晖 SMB 官方说明↗ 共享文件夹排查说明↗
威联通 QNAPQTS · SMB
  1. 登录 QTS，进入“控制台 → 网络和文件服务 → Win/Mac/NFS/WebDAV → Microsoft 网络”，启用 SMB。
  2. 在“权限 → 共享文件夹”中新建或选择归档目录。
  3. 为 PhotoHarbor 使用的账号授予读写权限，并限制匿名访问。
  4. 记录 NAS IP、共享目录、账号和密码；SMB 默认端口为 445。
  5. 如果设置了主机访问限制，确认 iPhone 所在网段没有被拒绝。
QNAP SMB 官方说明↗ 共享目录权限说明↗
飞牛 fnOSSMB / WebDAV / SFTP
  1. 进入“设置 → 文件共享协议”，开启 SMB；需要 SFTP 时进入“设置 → SSH”开启服务。
  2. 在“文件管理 → 我的文件 → 团队文件”中新建专用团队文件夹。
  3. 创建时允许该目录通过 SMB/WebDAV 等文件共享协议挂载。
  4. 为使用的账号授予“读写”权限，并确认该账号的文件共享可见范围包含此目录。
  5. 记录设备 IP、账号和目录原始路径。
飞牛文件共享权限说明↗ 团队文件夹说明↗
macOS文件共享 · SMB
  1. 打开“系统设置 → 通用 → 共享 → 文件共享”。
  2. 点击文件共享旁的信息按钮，在“选项”中开启“使用 SMB 来共享文件和文件夹”。
  3. 勾选允许通过 SMB 登录的 Mac 用户。
  4. 将归档目录加入共享文件夹，并给予该用户“读与写”权限。
  5. 记录 Mac 的局域网 IP、共享文件夹名称、用户名和密码；归档期间避免 Mac 进入睡眠。
Apple 官方 SMB 设置说明↗
Windows 11网络文件共享 · SMB
  1. 将当前网络配置为“专用网络”，并开启网络发现和文件及打印机共享。
  2. 在文件资源管理器中右键目标文件夹，选择“显示更多选项 → 授予访问权限 → 特定用户”。
  3. 为专用账号授予读取和写入权限；不建议长期使用无密码或 Everyone 完全控制。
  4. 确认 Windows 防火墙允许专用网络中的文件共享。
  5. 记录电脑 IP、共享名称、Windows 用户名和密码；上传期间保持电脑开机。
Microsoft 官方网络文件共享说明↗

点击“检查并保存”后，PhotoHarbor 会检查是否能够连接、创建测试内容、提交或重命名文件、列出目录并执行轻量读取。测试成功后才保存目标，临时探测内容会尽力清理。页面必须显示“可用于归档”后，再进入下一步。

04

允许 App 读取所选内容并访问目标

授予系统权限

照片权限

第一次从“上传”进入选择流程时，允许 PhotoHarbor 访问照片。建议选择完整访问；如果选择有限访问，只能处理已授权的照片，后续新增照片可能需要在系统设置中更新授权范围。

本地网络权限

连接 NAS、Mac 或 Windows 时，需要允许本地网络访问。若曾拒绝，可到“iOS 设置 → 隐私与安全性 → 本地网络”重新开启 PhotoHarbor。

云盘授权

云盘登录在服务商官方授权页面完成。PhotoHarbor 不接收云盘登录密码，只保存完成操作所需的 OAuth 凭据。

iCloud 原件

如果 iPhone 开启了“优化 iPhone 储存空间”，部分原件可能只在 iCloud 中。首次大批归档前应保持稳定网络、足够的本机临时空间和电量，让系统能够下载所选原件。

05

避免任务因网络策略暂停

检查网络与上传设置

Wi‑Fi

“仅在 Wi‑Fi 网络下上传”默认开启。开启时，如果当前只有蜂窝网络，新建任务仍会创建，但会显示“等待 Wi‑Fi”，接入 Wi‑Fi 或有线网络后自动继续。浏览、预览、播放和删除校验不受这个开关影响。

  • iPhone/iPad 与 NAS 或电脑处于同一 Wi‑Fi 或可互通的 VPN。
  • 避免使用开启“客户端隔离”的访客 Wi‑Fi。
  • NAS、电脑、外接硬盘和目标卷保持在线。
  • 归档大视频时连接电源，并避免电脑自动睡眠。
  • 云盘账号授权有效，目标文件夹仍存在且可写。
  • 若允许蜂窝上传，在“设置”页关闭“仅在 Wi‑Fi 网络下上传”，并留意流量消耗。

添加存储目标

存储目标是 PhotoHarbor 用来归档照片和视频的远端位置。添加前请先完成“准备工作”，确认目标目录可以连接并具有读写权限。

基础版可以配置 1 个可写目标；完整版或完整试用期可以配置多个目标。达到数量上限时，App 会先显示升级提示，不会进入添加表单。

  1. 目标页面
  2. 点击“+”
  3. 选择协议或云盘
  4. 填写信息或授权
  5. 选择归档文件夹
  6. 检查并保存
  7. 等待媒体库准备
01

打开入口

进入添加页面

  1. 打开 PhotoHarbor，进入“目标”页面。
  2. 点击右上角“+”；当前还没有目标时，也可以点击空状态中的添加按钮。
  3. 输入可选的“显示名称”。它只用于在 App 中识别目标，留空时会自动生成。
  4. 如果基础版已经配置了一个目标，App 会说明目标数量已达到上限，并提供升级入口。
此时不会上传照片

添加目标不会立即上传任何照片。只有后续创建归档任务并选择照片或视频后，上传才会开始。

对应 App 表单

填写服务器信息

类型必填内容特殊设置
SMB主机、共享文件夹、用户名、密码端口通常为 445；工作组或域环境才填写“SMB 域”
WebDAVHTTP/HTTPS、主机、端口、路径HTTPS 通常为 443，HTTP 通常为 80；HTTP 会显示未加密风险提示

技术详情：授权范围和过期时间

App 可能显示 OAuth scopes 和 token 到期时间，供排查授权问题使用。普通用户不需要修改这些值；授权过期时按提示重新登录即可。

05

协议与账号差异

确认特殊设置

SMB 域

家庭 NAS 通常留空，仅工作组、Active Directory 或企业域环境需要填写。

WebDAV HTTP/HTTPS

优先使用 HTTPS；HTTP 只用于完全可信的局域网，因为凭据和媒体内容不会被传输层加密。

SFTP 认证方式

密码与私钥二选一；只有私钥本身已加密时才填写私钥口令。

云盘账号切换

切换后重新授权，并重新选择与新账号对应的归档文件夹。

百度转码视频播放只影响远端视频播放
  • App 会显示百度账号会员状态。
  • 超级会员默认自动开启；非超级会员或未知状态默认关闭。
  • 用户可以手动覆盖，并通过“恢复默认”回到自动策略。
  • 此开关不影响上传、归档 proof 或 Safe Delete 判断。
技术详情不是必填设置

授权范围和 token 到期时间只用于查看与排障，不需要用户手工编辑。

先理解什么是归档证明

proof 是远端副本的可用证明

它表示远端文件已经经过当前策略要求的大小、可读性与预览性检查。只有通过 proof 的资源才会被记录为后续 Safe Delete 的依据。

上传完成仍需等待

文件已经传到远端，不代表所有后续检查均已结束。请以任务详情里的 proof 状态为准，不要仅凭上传百分比删除本机照片。

技术说明：当前 proof 策略

支持的存储会优先使用服务商提供的校验和。其他目标会在本机临时文件可用时，对远端头部、中段和尾部做抽样读取；只有本机临时文件已不存在且保留了校验和时，才会回退为流式读取远端文件完成校验。

无论采用哪种依据，任务还需要通过轻量读取与预览检查。proof 的含义始终是“满足当前归档证明策略”，而不是默认承诺每个文件都已全文逐字节比对。

05

处理等待、阻断与失败

等待 Wi‑Fi 或已暂停

接入允许的网络后会继续；手动暂停的任务需要在任务页点击继续。

iCloud、权限或资源组问题

保持网络、电量与照片权限；Live Photo 的静态照片和动态视频必须都可取得，缺失的一侧不会伪装为成功。

认证、空间、网络或远端读取失败

检查目标在线状态、VPN、账号、空间和目录权限；可恢复错误使用“重试”只处理仍需收口的资源。

预览失败或跳过重复文件

预览失败会阻断 proof；被冲突策略跳过的项目不会进入 Safe Delete，应保留本机原件或改用重命名重新归档。

06

proof 完成后再决定是否释放空间

资格按完整资源组判断

普通照片、视频以及 Live Photo 的全部必要资源均完成 proof 后，相关素材才可能出现在 Safe Delete。失败、跳过或远端已删除的项目不会获得资格。

安全删除

Safe Delete 是在你决定释放 iPhone 或 iPad 空间时使用的本机删除流程。它只处理本机照片库副本，不会删除 NAS、电脑或云盘中的远端原件。

请先查看候选和 proof，再决定是否发起删除。远端文件、归档任务和 proof 历史不会因为删除本机副本而被移除。

01

先从 Safe Delete 候选开始

打开 Safe Delete 后，页面会把可复核候选与被阻断项目分开显示。没有候选时，通常表示 proof 尚未完成、资源不完整，或本机照片已经不在照片库中。

Safe Delete 不会自动执行

即使项目符合资格，PhotoHarbor 也不会自动删除本机照片；每次删除仍需要你主动确认。

02

查看候选、proof 与阻断原因

可删除候选

显示本机素材、所属目标、proof 状态与预计可释放空间。打开详情可查看对应的远端路径和证明记录。

Live Photo 成组判断

Live Photo 的静态照片和动态视频都必须具备有效 proof；其中任意资源缺失、失败或已被标记远端删除，整组都不会进入候选。

阻断项目

proof 未完成、冲突时跳过、远端副本已删除、资源组不完整或照片权限状态变化时，会显示原因而不是允许删除。

03

“删除照片”默认复用已有 proof

点击“删除照片”时，App 默认复用已保存的 proof 来准备删除确认，不会为了开始确认而自动重新读取远端文件。这让你在 NAS 离线或不在家时，仍能基于已完成的归档证明进入复核。

需要更强确认时，再主动再次校验

如果你希望确认远端副本此刻仍然可读，请使用“再次校验”。它是额外复核，不是默认删除流程的隐含步骤。

04

按需主动再次校验远端

  1. 在 Safe Delete 中选择“再次校验”。
  2. App 重新连接目标并检查候选资源的远端可读性。
  3. 通过的项目进入本次删除确认；未通过的项目保留为阻断，不会被删除。
多个目标可部分通过

当候选来自多个目标时，能连接并通过检查的项目可以继续；认证失效、VPN 断开或远端读取失败的项目不会混入确认列表。

05

完成双确认后才删除本机副本

1

准备确认

App 汇总即将删除的项目数量与预计释放空间，并生成短时有效的确认状态。

2

再次确认

在确认对话框中核对内容后，才会向 iOS 照片库请求删除本机照片。

3

遇到变化则停止

确认过期、候选变化或 proof 失效时会阻断操作，需要重新回到候选列表确认。

06

理解删除后的结果与常见阻断

删除完成后，本机项目从系统照片库移除，PhotoHarbor 会记录删除历史与释放空间。iOS “最近删除”的保留和恢复规则由系统照片库决定，PhotoHarbor 不承诺可恢复期限。

不能删除时怎么办

proof 未完成
返回归档任务，等待或重试失败资源。
远端副本已删除
该 proof 已不能作为删除依据；请重新归档并完成 proof。
再次校验失败
检查网络、VPN、认证和远端文件可读性，未通过项目不会被删除。
确认已过期或候选变化
重新打开候选并再次发起删除确认。

浏览与恢复

媒体库用于继续浏览、预览、分享或恢复远端照片和视频。它不会因为你打开、播放或看到缩略图而自动上传本机内容，也不会自动删除本机原件。

浏览体验会优先使用已准备的缩略图和缓存；缓存预览不能替代远端原件，也不能单独作为 Safe Delete 的依据。

01

先理解媒体库中的两类内容

已归档并有 proof 的项目

这些项目来自 PhotoHarbor 的归档记录。只要远端副本仍有效，相关 proof 可用于后续 Safe Delete 判断。

扫描发现的远端媒体

这些是 App 在目标中发现的已有文件，可以浏览、预览、分享或保存回 iPhone，但不因此获得 Safe Delete 资格。

02

按时间或文件夹浏览

时间线浏览

按年、月、日查看远端媒体，适合回顾拍摄时间与快速定位最近归档的内容。

文件夹浏览

从目标根目录进入目录，适合按项目、年份或 NAS 原有结构查看文件；进入具体目录后也可使用“上传到这里”。

建库仍在进行时

扫描和缩略图准备达到可浏览条件后即可先进入媒体库，剩余内容会在后台继续补齐，不需要一直停留在目标详情页。

03

正确理解缩略图、预览与原件

缩略图

用于快速展示网格和目录封面。App 会优先复用已准备的小图，必要时再从远端生成。

预览与播放

打开项目后会按需读取远端内容。网络慢、设备休眠或授权失效时可能需要等待、重试或重新连接。

个别缩略图失败

不直接代表原照片或视频损坏；可稍后重新打开预览、重新扫描或等待网络恢复后重试。

缓存预览不能替代远端原件

缓存用于加快再次浏览，不是另一份可用于 proof 或 Safe Delete 的远端备份。

04

把远端素材保存回 iPhone

  1. 打开照片、视频或 Live Photo 的预览页，选择“保存回 iPhone”。
  2. App 从远端准备所需资源，并请求系统照片库的添加权限。
  3. 保存完成后，新副本会出现在 iPhone 或 iPad 的照片库中；网络中断或权限被拒绝时不会显示为成功。

Live Photo 会成组恢复

保存 Live Photo 时，PhotoHarbor 会同时准备静态照片和动态视频，并作为一组写入系统照片库；其中一项不可用时会提示失败，不会伪装成完整 Live Photo。

05

按用途分享高清预览或原件

高清预览分享

适合快速发送图片预览。App 会先准备可分享的高清预览，首次准备可能需要等待，之后可复用缓存。

原件分享

适合需要完整照片、视频或 Live Photo 文件的场景。App 必须从远端下载并准备资源，耗时与网络、文件大小和访问权限有关。

受限或失败时

基础版的高分辨率预览和远端原件分享可能显示相应的访问提示；不要把分享成功理解为新的归档 proof。

06

谨慎删除远端文件或文件夹

远端删除会删除实际远端文件

它直接作用于 NAS、电脑共享目录或云盘中的原始文件，不能替代 Safe Delete，也不会删除本机照片。删除前必须确认目标、当前目录和所选项目。

如果删除的是已归档副本，相关远端 proof 将不再可用于 Safe Delete；本机照片会保留，但需要重新归档并完成 proof 后才能再次进入安全删除候选。正在使用该目录的可恢复归档任务也应先完成、暂停或移出该目录。

07

按需使用官方网页播放

实验性功能：打开云盘官方播放页面

当设置中已开启官方网页播放，并且对应目标是 Dropbox、Google Drive 或 OneDrive 时，视频预览页可提供打开服务商官方网页的入口。

该入口依赖你在 Safari 中已有的服务商登录状态，不会创建公开分享链接，也不保证服务商网页一定能够播放、预览或保持登录。它只用于辅助浏览，不参与上传、proof 或 Safe Delete 判断。
